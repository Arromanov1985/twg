# TerraWater Equipment Selector

Программа подбора оборудования по анализу воды с формированием КП.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Если PDF не формируется на конкретном ПК, скачайте HTML и в браузере выберите **Печать -> Сохранить как PDF**.

## Где менять данные

- `data/water_analysis.xlsx` - исходный пример анализа воды.
- `data/equipment_catalog.xlsx` - каталог оборудования, цены, картинки.
- `data/selection_rules.xlsx` - правила подбора по параметрам воды.
- `templates/kp_template.html` - HTML-шаблон коммерческого предложения.
- `assets/equipment/` - картинки оборудования.

## Как работает

1. Пользователь вводит клиента и параметры анализа воды.
2. Программа применяет правила подбора.
3. Формирует комплектацию, цену и причины подбора.
4. Генерирует HTML КП и PDF КП.
